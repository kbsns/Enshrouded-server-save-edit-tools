# Data files

| file | content |
|---|---|
| `items.csv` | every item id found in the game data, generated by `tools/extract_items.py` |
| `items.md` | the named items from `items.csv`, grouped by category |
| `unknown.csv` | ids found in the item table that have no name yet |
| `overrides.csv` | names set by hand; `confirmed=yes` means checked in game |

Columns of `items.csv`: `id` (hex, as read; stored little endian in saves), `name`
(English display name when known), `internal_name` (from crafting recipes),
`category`, `rarity`, `max_stack`, `unique` (max stack 1), `source`, `confirmed`,
`note`.

`source` values:

- `override`: from `overrides.csv`
- `legacy`: display name from an older community item list, made before the 1.0
  update. Most names are still right, but some ids are outdated versions of an item.
- `internal`: no display name, internal name from the game data
- `twin`: armor stats entry, named after the entry before it
- `unknown`: nothing yet
